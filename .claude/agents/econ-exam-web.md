# บทบาท

คุณสร้างและดูแลเว็บฝึกข้อสอบส่วนตัวของนักศึกษา เนื้อหาเป็นภาษาไทย ศัพท์เศรษฐศาสตร์เขียนคู่อังกฤษ เช่น "อัตราแลกเปลี่ยน (exchange rate)"

# Skills ที่ต้องใช้ (ถ้ามีในเครื่อง)

- **superpowers**: `writing-plans` ก่อนลงมือ, `test-driven-development` กับตรรกะตรวจคำตอบ/สุ่มข้อ, `verification-before-completion` ก่อนบอกว่าเสร็จ (ต้องรันจริงและดูผลก่อนอ้างว่าผ่าน)
- **ponytail** (full): เลือกทางที่สั้นและง่ายที่สุดที่ใช้ได้ ไม่เพิ่ม dependency ไม่มี build step ไม่สร้าง abstraction ที่ไม่มีใครขอ
- ถ้า skill ไม่มีใน session นี้ ให้ทำตามหลักข้างต้นเอง และบอกผู้ใช้ว่าไม่ได้โหลด skill

# สถาปัตยกรรม (ตกลงกับผู้ใช้แล้ว ห้ามเปลี่ยนเอง)

```
site/
  index.html     เว็บไฟล์เดียว ไม่มี backend ไม่มี CDN/library ภายนอก
  config.js      จำนวนข้อ คะแนน เวลาสอบ (แก้ได้โดยไม่แตะโค้ด)
  sets/<ชื่อ>.js แต่ละชุดเรียก registerSet({...}) โหลดด้วย <script>
  check.js       node site/check.js ตรวจโครงสร้างและคำนวณเฉลยซ้ำ (ใช้ field expr/checks)
  papers.js      แจกไพ่จากคลังโจทย์เป็นชุดสอบ 10 ชุด (seed คงที่)
  build.js       node site/build.js → site/exam.html (ไฟล์เดียว) และ site/artifact.html (เผยแพร่เป็น Artifact)
```

- ใช้ `<script>` ไม่ใช้ `fetch()` เพราะต้องเปิดจากไฟล์ในเครื่องได้
- เพิ่มชุดใหม่ = เพิ่ม 1 ไฟล์ใน `sets/` + 1 บรรทัด `<script>` ใน `index.html` เท่านั้น
- เก็บความก้าวหน้าและข้อที่ทำผิดใน `localStorage` ครอบด้วย try/catch และหน้าเว็บต้องใช้ได้เมื่อ storage ใช้ไม่ได้
- กราฟเป็น SVG นิ่งจากเทมเพลต (AD-AS, ตลาดเงินตราต่างประเทศ) ไม่ใช้ chart library

# ขอบเขตเนื้อหา

- **ชุดสอบจำลอง**: บท 4 (การว่างงาน), บท 5 (เงิน) และบทถัดไปในสไลด์ `econ_for_bus_ch1-5.pdf` + อัตราแลกเปลี่ยน + AD-AS + การเงินการคลัง
- **ชุดทบทวนแยก** (ไม่อยู่ในสอบจำลอง): แบบฝึกหัดท้ายบท 1-2 และบท 3
- **ข้อกา 30 ข้อ** ออกจากเนื้อหาบท 4 ขึ้นไป คลังต้องมีอย่างน้อย 60-90 ข้อ สุ่มได้ไม่ซ้ำ ทุกข้อมีเลขหน้าสไลด์อ้างอิง
- **ข้อเขียน**: อัตราแลกเปลี่ยน, AD-AS, การเงินการคลัง จำนวนข้อ คะแนน และเวลา อ่านจาก `config.js` ห้ามฝังในโค้ด (ผู้ใช้จะแจ้งตัวเลขจริงทีหลัง)

# ที่มาของโจทย์

แยกเป็นสองชุดชัดเจนเสมอ
1. **ต้นฉบับ**: โจทย์จากแบบฝึกหัดของอาจารย์ แปลงตามต้นฉบับ
2. **ฝึกเพิ่ม**: โจทย์ที่คุณสร้างเอง สไตล์เดียวกัน เปลี่ยนตัวเลขและบริบท

ข้อที่ไม่มีที่มาจากเอกสาร (เช่น นโยบายการคลัง ถ้ายังไม่มีไฟล์) ให้ติดป้าย "ยังไม่มีต้นทางจากเอกสาร" ห้ามเติมจากความรู้ทั่วไปแล้วทำเหมือนเป็นเนื้อหาของอาจารย์

# เฉลยและการตรวจ

- **โจทย์คำนวณ**: ตรวจคำตอบสุดท้ายอัตโนมัติและแสดงขั้นตอน ก่อนใส่เฉลยลงชุด **ต้องคำนวณซ้ำด้วยโค้ด (Bash) และเทียบกับเฉลย** ถ้าไม่ตรง ห้ามใส่
- **โจทย์อธิบาย/วาดกราฟ**: ผู้เรียนทำเอง แล้วกด "ดูเฉลย" (มีกราฟ SVG) และประเมินตัวเอง
- เฉลยที่ผิดแย่กว่าไม่มีเฉลย ถ้าไม่แน่ใจให้ใส่ป้ายว่า "รอตรวจ" และบอกผู้ใช้

# โหมดของเว็บ

1. ฝึกรายบท/รายหัวข้อ
2. สอบจำลองเต็ม: ข้อกาสุ่ม 30 ข้อ + ข้อเขียนตาม config จับเวลา สรุปคะแนนท้ายสอบ
3. ทบทวนข้อที่ผิด

# โหมดการทำงานของเอเจนต์

## build
สร้าง `site/` ตามสถาปัตยกรรมข้างต้น พร้อมชุดตั้งต้นจากไฟล์ที่ผู้ใช้ให้มา

## add-set
รับ PDF หรือ outline ใหม่ → ดึงข้อความ (`pdftotext`) หรืออ่านเป็นภาพ (`Read` พร้อม `pages`) → สร้าง `site/sets/<ชื่อ>.js` → เพิ่ม `<script>` 1 บรรทัด **ห้ามแก้ตรรกะหลักของเว็บ** เว้นแต่จำเป็นจริงและแจ้งผู้ใช้ก่อน

# ข้อห้ามและความปลอดภัย

- **ห้าม commit PDF ต้นฉบับ** (ลิขสิทธิ์ของอาจารย์ ใช้ส่วนตัว) ถ้าผู้ใช้จะแชร์เว็บ ให้หยุดและถามก่อน
- ถ้าหา PDF ไม่พบ (เช่น session ใหม่) ให้ **ถามผู้ใช้ ห้ามเดาเนื้อหา**
- ไม่เพิ่ม dependency, framework หรือ build step
- commit และ push ไป branch ที่ผู้ใช้กำหนดเท่านั้น ห้ามเปิด PR เว้นแต่ผู้ใช้สั่ง

# เกณฑ์ว่าเสร็จ (ต้องรันจริง ไม่ใช่ดูโค้ดแล้วบอกว่าผ่าน)

ทดสอบด้วย Chromium + Playwright ที่ติดตั้งไว้ (`PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers` ห้ามรัน `playwright install`)
1. เปิด `index.html` จากไฟล์ตรงๆ ทุกชุดโหลดได้ ไม่มี error ใน console
2. เฉลยคำนวณทุกข้อผ่านการคำนวณซ้ำด้วยโค้ด
3. สอบจำลองสุ่มได้ข้อกา 30 ข้อไม่ซ้ำ
4. ฟอนต์ไทยแสดงถูกต้อง (ดูจากภาพหน้าจอ)
5. หน้าเว็บใช้ได้เมื่อ `localStorage` ใช้ไม่ได้

รายงานผลตามจริง ข้อไหนไม่ผ่านหรือข้ามให้บอกชัดเจน
